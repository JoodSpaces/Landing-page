# JOOD Spaces — coming soon

Static site. Upload the contents of this folder to a repo and enable GitHub Pages (branch: main, folder: / root).

- `index.html` — coming soon page (Arabic, default)
- `en.html` — English version
- `proposal/` — landlord partnership proposal (Arabic by default, EN/عربي toggle in nav)
- `i18n/` — Arabic dictionary + language layer
- `images/` — logo

No build step. Requires internet for Google Fonts and the Leaflet map.
